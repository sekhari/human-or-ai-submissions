# Workspace for shifenghong only

All of shifenghong's approach on training a *logistic regression* model will be stored within this folder.


## Approach

**Train a logistic regression model on embedded text on the *train_starter_2000.csv* dataset**

> We are going to use [this embedding model](https://ollama.com/library/embeddinggemma-2:270m)

train_starter.csv dataset is a stratified dataset from the complete *train.csv*. It has 2000 datapoints, split evenly between the two labels.

[Link to Kaggle compeition page ](https://www.kaggle.com/competitions/cornell-tech-cs-5785-combined-2026-ai-vs-human-text)


## Shape of data

2000 rows of data with shape (id, text, label), each column-separated row is a datapoints.

For label, 0 represent *human-written text*, 1 represent *AI-generated text*


## Expected output

2000 rows of data with shape (id, label)

label is real number between *[0,1]*, representing the probability that the passage was generated by AI.
