# Model A: word TF-IDF + logistic regression

Person 1 contribution for `submissions/group-number-17/`. The classifier predicts
`P(label=1)`, where label 1 means AI-generated text. It uses word unigrams and
bigrams. Every TF-IDF vocabulary and IDF vector is fitted on training rows only.

## Shared validation split

This experiment used the **exact 2,000 IDs** in this team's `val_ids.csv` (1,000
per label). The local experiment manifest and the committed CSV have zero ID
membership differences. The remaining 8,000 labeled rows were used for model
selection and learning curves. Seed: 42. The 2,000-row starter file is already
part of `train.csv` and was not added to training.

## Reproduce from this team directory

Place the original Kaggle `train.csv`, `test.csv`, and `sample_submission.csv`
in a local `data/` folder. The repository ignores that folder. From
`submissions/group-number-17/`, run:

```bash
python -m pip install -r requirements-logistic.txt

python logistic_model.py split \
  --train data/train.csv --text-col text --label-col label --id-col id \
  --positive-label 1 --validation-size 2000 --seed 42 \
  --validation-ids val_ids.csv --manifest data/logistic_split.json

python logistic_model.py experiment \
  --train data/train.csv --text-col text --label-col label --id-col id \
  --positive-label 1 --manifest data/logistic_split.json \
  --c-values 0.1 1 10 --max-features 20000 50000 100000 \
  --train-sizes 500 1000 2000 5000 8000 \
  --output-dir data/logistic_results

python logistic_model.py submit \
  --train data/train.csv --test data/test.csv \
  --sample-submission data/sample_submission.csv \
  --text-col text --label-col label --id-col id --positive-label 1 \
  --prediction-col label --manifest data/logistic_split.json \
  --results-dir data/logistic_results \
  --output data/submission_logistic.csv --candidate-only
```

The last command only writes a local CSV. It refits the selected logistic
configuration on all 10,000 labeled examples and checks the output against
the sample submission format. It does **not** upload to Kaggle. The validation
AUROC above belongs to the 8,000-row fit, not this full-data refit. This
model is one candidate; compare it with SVM, Naive Bayes, and the ensemble
on the shared validation IDs before choosing the team's final submission.
