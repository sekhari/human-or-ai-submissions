# Team submissions

Each team owns exactly one directory:

```text
submissions/<kaggle-team-name>/
```

Use the same Kaggle team name as on the competition leaderboard (lowercase, hyphens for spaces).

Do not modify `_example_team/` except as a local reference — copy it if helpful:

```bash
cp -R submissions/_example_team submissions/<kaggle-team-name>
```

Then replace the placeholder contents with your real pipeline.
